API Documentation

RESTful JSON API · Command service http://localhost:8080/api/v1 (writes and reads) · Query service http://localhost:8081/api/v1 (reads)

Overview

The OpenFactstore API is a RESTful HTTP API that accepts and returns JSON. All endpoints follow standard HTTP semantics — GET for retrieval, POST to create, PUT/PATCH to update, and DELETE to remove.

When the server is running, an interactive Swagger UI is available at http://localhost:8080/swagger-ui.html with full schema documentation and a built-in request executor.

ℹ️
The OpenAPI specification (JSON) is available at http://localhost:8080/api-docs and can be imported into Postman, Insomnia, or any OpenAPI-compatible tool.

Authentication

Authentication is enforced by default. Every request needs a credential, sent as Authorization: Bearer <key>; without one the API answers 401. scripts/bootstrap-env.sh writes a bootstrap admin key to .env (SECURITY_BOOTSTRAP_API_KEY) for first use; create service-account keys for CI and revoke the bootstrap key afterwards. 

export FACTSTORE_TOKEN="$(grep '^SECURITY_BOOTSTRAP_API_KEY=' .env | cut -d= -f2-)"
curl -s -H "Authorization: Bearer $FACTSTORE_TOKEN" http://localhost:8080/api/v1/flows | jq .

Keys, scopes and rotation: docs/api-authorisation.md.

API Resources

Resource Base Path Description
Flows /api/v1/flows Compliance flow definitions (templates of required checks)
Trails /api/v1/trails Per-release deployment evidence trails; archived, never deleted
Attestations /api/v1/trails/{id}/attestations Individual compliance evidence records attached to a trail
Security Scans /api/v1/trails/{id}/security-scans Security scan results (OWASP ZAP, Snyk, Trivy)
Approvals /api/v1/approvals Release approval workflows and sign-offs
Deployment Policies /api/v1/deployment-policies Policy definitions controlling deployment gate behaviour
Deployment Gate /api/v1/gate/evaluate Evaluate whether an artifact is cleared for a target environment
Environments /api/v1/environments Tracked deployment environments (dev, staging, production); archived, never deleted, so snapshot history is kept
Data Retention /api/v1/admin/retention, /api/v1/legal-holds Per-organisation retention policies, legal holds and the retention job
Organisations /api/v1/organisations Multi-tenant organisation management
OPA Policies /api/v1/opa OPA bundle management and policy evaluation
Regulatory Frameworks /api/v1/frameworks SOX, PCI-DSS, GDPR framework definitions and control mappings
Compliance /api/v1/compliance Framework compliance assessment and gap analysis
Metrics /api/v1/metrics Compliance metrics and aggregated statistics

Common Patterns

Dry-run Header

All write operations (POST, PUT, DELETE) support a dry-run mode. Add the X-Factstore-Dry-Run: true header to validate and simulate without persisting: 

X-Factstore-Dry-Run: true

Error Responses

All errors follow a consistent JSON structure:

{
  "status": 404,
  "error": "Not Found",
  "message": "Trail with id 'abc-123' not found",
  "path": "/api/v1/trails/abc-123"
}

Example Requests

List all Flows

curl -s -H "Authorization: Bearer $FACTSTORE_TOKEN" http://localhost:8080/api/v1/flows | jq .

Create an Attestation

curl -s -X POST http://localhost:8080/api/v1/trails/<trail-id>/attestations \
  -H "Authorization: Bearer $FACTSTORE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "security-scan",
    "status": "PASSED",
    "details": "Trivy: 0 critical findings"
  }' | jq .

Evaluate Deployment Gate

curl -s -X POST http://localhost:8080/api/v1/gate/evaluate \
  -H "Authorization: Bearer $FACTSTORE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "artifactSha256": "sha256:<64 hex characters>",
    "environmentId": "<environment-id>"
  }' | jq .

Record a Security Scan

curl -s -X POST http://localhost:8080/api/v1/trails/<trail-id>/security-scans \
  -H "Authorization: Bearer $FACTSTORE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "tool": "trivy",
    "criticalVulnerabilities": 0,
    "highVulnerabilities": 1,
    "reportUrl": "https://ci.example.com/scans/build-42"
  }' | jq .
